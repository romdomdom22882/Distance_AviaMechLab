# Distance_AviaMechLab

## Проект: авторизация в Microsoft Access 2010

В репозитории добавлен учебный проект авторизации для **Access 2010** (таблицы пользователей/ролей, форма входа, VBA‑модули для проверки пароля, блокировка при подборе, аудит входов).

См. подробности и инструкции по сборке в `access2010-auth/README.md`.
